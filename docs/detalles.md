# Detalles sobre ramas en Git

Una **rama** es una línea independiente de desarrollo. Los cambios hechos en una rama no afectan a las demás hasta que se fusionan con `git merge`.

- `git branch nombre` crea una rama.
- `git checkout nombre` cambia de rama.
- `git merge nombre` une una rama con la actual.
